# m68k minimum platform

## M0 direction

MikrOS Linux treats classic MMU Linux and no-MMU Linux as distinct target classes.

For the classic workstation/home-computer m68k target, the initial baseline is **68020 + a supported MMU**, not plain 68000.

This keeps the first m68k profile aligned with normal virtual-memory Linux and with machines such as suitably equipped Amiga, Atari and Macintosh systems.

## CPU classes

- **68000 / 68010** — not part of the initial MMU Linux profile. Potential no-MMU research belongs in a separate later profile.
- **68020** — initial CPU ISA floor for the classic MMU profile; requires an appropriate external MMU/platform combination.
- **68030** — natural early Tier-1 candidate because the MMU is integrated and it is common in classic m68k systems.
- **68040 / 68060** — compatibility/performance targets after the minimum profile works.
- **ColdFire / other m68k families** — separate later qualification; do not assume classic 68k machine compatibility.

## Proposed M0 reference split

### Generic/minimum ISA
68020 + MMU

### Practical reference CPU
68030

The distinction matters: 68020 represents the architectural floor we want to preserve, while 68030 is much easier to describe and emulate as a complete CPU+MMU baseline.

## Machine qualification

CPU support alone does not imply machine support. Each machine family needs a kernel configuration, boot method, storage/console path and emulator/hardware qualification.

Initial machine candidates:

- Amiga
- Atari
- Macintosh
- QEMU/generic m68k reference where useful

## M0 questions still open

- exact Linux release/LTS baseline;
- exact supported 68020+MMU combinations in that baseline;
- minimum RAM for a useful MikrOS userspace;
- libc choice and compiler flags;
- emulator reference per machine family;
- whether a no-MMU m68k profile is maintainable enough to belong in MikrOS Linux.

No 68000 support is promised by the main m68k profile.
