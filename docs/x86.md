# x86 minimum platform

## Current upstream baseline

Current upstream Linux no longer supports 80386 or 80486 processors. For a current upstream 32-bit x86 kernel, the generic minimum CPU family is i586.

Therefore MikrOS Linux separates two concepts:

- **current-upstream profile** — i586/Pentium-class minimum;
- **legacy-kernel research** — older kernels may later be qualified for 386/486, but they are not the primary maintained MikrOS Linux baseline.

## M0 x86 target

Initial Tier-1 candidate: generic i586 without assuming i686-only instructions.

This is intentionally conservative and leaves room for Pentium-class and compatible embedded CPUs.

## Qualification still required

- exact kernel release/LTS policy;
- libc and compiler minimum;
- RAM/storage measurements;
- QEMU reference machine;
- representative physical/alternate emulator tests.

A CPU is not supported merely because the kernel has a configuration label for it.
